# 青年发展部官方网站 · 使用说明

> 华中师范大学政治与国际关系学院团委 · 青年发展部
> 纯静态网站（HTML + CSS + JS），零依赖、可离线打开、可直接部署。

---

## 一、最快上手

**双击 `index.html`** 即可在浏览器中打开整站——不需要联网、不需要安装任何东西。

| 页面 | 文件 | 主要内容 |
| --- | --- | --- |

> 小技巧：在 VS Code 里按 `Ctrl + Shift + F` 打开“全项目搜索”，输入要改的那句话，就能一次看到它在哪些页面出现过。

### 2. 换图片

**推荐做法（替换 data URI 键）**：

1. 把新图片放到部门文件夹里；
2. 打开 `build_assets.py`，修改 `SOURCES` 字典中对应键的源文件路径；
3. 在网站目录下运行：

   ```bash
   python build_assets.py
   ```

   脚本会重新压缩图片并覆盖 `js/assets-data.js`，全站图片随之更新。

**临时做法**：直接把某个 `<img>` 的 `src="..."` 改成真实相对路径（例如 `assets/新照片.jpg`），并把该标签上的 `data-asset="…"` 属性删掉，以免被脚本覆盖。

### 3. 加新页面

1. 复制任意一个内页（例如 `notices.html`）另存为新文件名；
2. 改 `<title>`、面包屑、`<h2>` 与正文；
3. 把 `.mainnav` 里的 `<a class="nav-link">` 增加一项，并把 `active` 类挪到新页面那一条；
4. 运行 `python check_site.py` 确认无误。

## 四、自检（改完后建议跑一次）

```bash
python check_site.py
```

它会检查：

- 每个页面引用的图片键是否都能在 `js/assets-data.js` 里找到；
- 所有站内链接、图片、样式、脚本的目标文件是否存在；
- 十个页面是否都带有统一的站头、导航、页脚与脚本；
- 导航 `active` 是否唯一、标签是否成对闭合、页内锚点是否存在。

全部通过时输出 `错误 0 项`。

## 五、部署到服务器 / GitHub Pages

网站是纯静态的，**把 `青年发展部官网` 整个文件夹上传即可**，入口文件是 `index.html`。

- **学校服务器 / 学院空间**：用 FTP 或后台文件管理，把文件夹内所有文件上传到网站根目录。
- **GitHub Pages**：新建仓库 → 上传这些文件 → Settings → Pages → 选择分支与根目录。
- **校园内网共享文件夹**：直接把整个文件夹拷过去，双击 `index.html` 也能打开。

### 部署前务必注意

`works.html` 里的材料链接指向部门本地工作文件夹（`../青年发展部/…`、`../2026-2027年度青年发展部部长/…`）。这些文件包含团员信息、入党申请人名单等工作数据：

- 若**不允许公开访问**（推荐）：上传前删除 `works.html` 中的材料链接，或整页改为“材料请到部门共享盘获取”；
- 若**允许公开**：需要把对应文件夹一并上传，并在服务器上设置访问权限（例如加密码目录）；
- 也可以在导航中去掉“工作材料”这一项，仅保留其他页面。

### 上线前建议核对

- `contact.html`：“联系渠道”一行是否要改成具体方式（现为“通过所在团支部或学院团委联系”）；
- 页面中的部门数据与工作动态是否需要随本学年进展更新。

> 邮箱、公众号、办公地址、招新信息、星级团员评定、成员分工均已按需求删除，无需再填写这些内容。
